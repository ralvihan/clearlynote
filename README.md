# Clearlynote

![Clearlynote](docs/logo_clearlynote.svg)

A personal debt notebook. Track debts, installments, due dates, and late fines.

Demo: https://clearlynote.web.app

Built with HTML, CSS, JavaScript, and Firebase (Auth, Firestore, Hosting).

## Run

1. Fill in `firebaseConfig` in `app.js` with your own Firebase project config.
2. Run `npx serve .`

## Deploy

```
firebase deploy --only hosting
```
